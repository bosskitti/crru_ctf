คู่มือเชื่อมต่อระบบ OPENVPN

📥 ดาวน์โหลดไฟล์โปรไฟล์ OPENVPN ประจำตัว (CRRULEARNCTF_{{ safe_username|upper }}.OVPN)

ขั้นตอนการเชื่อมต่อใช้งานบน KALI / LINUX (2 รูปแบบ)

1
💻 รูปแบบที่ 1: เชื่อมต่อผ่าน Terminal Command (แนะนำ ⚡)
วิธีที่รวดเร็วที่สุดสำหรับสาย CLI
1. ติดตั้งแพ็กเกจ OpenVPN (หากเครื่องยังไม่มี):
sudo apt update && sudo apt install openvpn -y
2. เปิด Terminal ในโฟลเดอร์ที่โหลดไฟล์ไว้ แล้วสั่งรัน OpenVPN:
sudo openvpn crrulearnctf_{{ safe_username }}.ovpn
เมื่อพบข้อความ Initialization Sequence Completed แสดงว่าเชื่อมต่อสำเร็จแล้ว!
2
🖥️ รูปแบบที่ 2: Import ผ่าน GUI Network Manager (ตามภาพ)
ใช้งานง่ายผ่านหน้าจอ Kali Desktop
  1. คลิกไอคอน Network Connections มุมขวาบนของแถบงาน Kali ➔ เลือก VPN Connections ➔ คลิก Configure VPN...
  2. ในหน้าต่าง Network Connections กดปุ่ม `+` (Add Connection) ➔ เลื่อนลงล่างสุดเลือก Import a saved VPN configuration...
  3. เลือกไฟล์ crrulearnctf_{{ safe_username }}.ovpn ที่ดาวน์โหลดมา ➔ กดปุ่ม Save
  4. สวิตช์เปิดสวิตช์ ON ที่ชื่อ VPN ในเมนูด้านบน เพื่อเปิดใช้งานท่อ VPN ได้ทันที!
