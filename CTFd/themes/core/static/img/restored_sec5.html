🚀 5. PENETRATION TESTING LIFECYCLE (วงจรการเจาะระบบและความเชื่อมโยงกับ VA) PENTEST ARCHITECTURE

กระบวนการ 3 ระยะหลัก (Phases) และ 6 ลำดับขั้นตอนการเจาะระบบ (Stages)

แผนภาพแสดงตำแหน่งของแต่ละขั้นตอน พร้อมระบุตำแหน่งสำคัญของ Vulnerability Assessment (VA) ในวงจรการทำงาน
⚡ 3 PHASES & 6 STAGES
🎯
การทำ Vulnerability Assessment (VA) อยู่ในส่วนไหนของ Flow การเจาะระบบ?
PRE-EXPLOITATION ➔ STAGE 2
จากแผนภาพสถาปัตยกรรมด้านบน การประเมินและสแกนหาช่องโหว่ความปลอดภัย หรือ Vulnerability Assessment (VA) จะตั้งอยู่ในระยะ PRE-EXPLOITATION โดยเฉพาะในขั้นตอน Stage 2: Scanning (การสแกนพอร์ตและสแกนช่องโหว่) ซึ่งมีความสำคัญอย่างยิ่งต่อกระบวนการเจาะระบบทั้งหมด:
🔍 1. ค้นหาและชี้เป้าจุดอ่อน (Pinpoint Flaws)
หลังจากรวบรวมข้อมูลทั่วไปใน Stage 1 แล้ว Pentester จะใช้เครื่องมือสแกน (เช่น Nmap NSE, Nessus, OpenVAS) เพื่อตรวจหาบริการที่เปิดอยู่ และนำเวอร์ชันไปเทียบกับฐานข้อมูล CVE เพื่อค้นหาช่องโหว่ความปลอดภัยที่ตรงกัน
⚖️ 2. คัดกรองและประเมินผลกระทบ (Risk Prioritization)
การทำ VA ช่วยนำคะแนน CVSS Score มาจัดลำดับความเร่งด่วน เพื่อให้ผู้ทดสอบเลือกช่องโหว่ที่มีโอกาสสำเร็จสูงสุด มีความคุ้มค่า และลดความเสี่ยงที่จะทำให้ระบบจริงของลูกค้าหยุดชะงัก (Avoid DoS)
🚀 3. สะพานเชื่อมสู่การบุกจริง (Bridge to Exploitation)
ผลลัพธ์จากการทำ VA ใน Stage 2 (เช่น ทราบว่ามีช่องโหว่ RCE รหัส CVE-2019-0708) จะกลายเป็น "เป้าหมายที่แท้จริง" สำหรับส่งต่อไปยัง Stage 3: Gaining Access เพื่อดาวน์โหลดหรือเขียนโค้ดยิงโจมตี (Exploit) เข้าควบคุมเครื่องเหยื่อต่อไป
💡 สรุปบทบาท: หากไม่มีการทำ Vulnerability Assessment ใน Stage 2 ผู้เจาะระบบจะไม่รู้ว่าระบบเป้าหมายมีช่องโหว่ใดอยู่บ้าง และไม่สามารถข้ามไปสู่ระยะ Exploitation ได้อย่างแม่นยำ
