🖥️ ค่าเริ่มต้น Initial TTL ตามประเภทของระบบปฏิบัติการ (OS Baseline)

🧪

ปฏิบัติการจริงบน Kali Linux: พิสูจน์ค่า TTL จากการ Ping เครื่องเป้าหมายจริง

เปรียบเทียบผลลัพธ์จากการใช้คำสั่ง ping ทดสอบเครื่องเป้าหมาย 2 เครื่องในเครือข่ายทดลองเดียวกัน
⚡ LIVE LAB DEMONSTRATION
📸 ภาพถ่ายหน้าจอเทอร์มินัล Kali Linux: คำสั่ง Ping ตรวจสอบ IP 192.168.255.128 เทียบกับ 192.168.255.129
🐧 โฮสต์เป้าหมายที่ 1 (IP: 192.168.255.128)
ttl=64
• คำสั่ง: ping 192.168.255.128
• ค่าที่ได้รับ: ttl=64 (เวลาตอบสนอง avg = 0.112 ms)
• การวิเคราะห์ OS: ได้รับค่า ttl=64 เต็มจำนวนโดยตรง แสดงว่าเป็นระบบปฏิบัติการตระกูล Linux / Unix อย่างแน่นอน และอยู่ในวงเครือข่ายแลนเดียวกัน (0 Hop)
🪟 โฮสต์เป้าหมายที่ 2 (IP: 192.168.255.129)
ttl=128
• คำสั่ง: ping 192.168.255.129
• ค่าที่ได้รับ: ttl=128 (เวลาตอบสนอง avg = 0.774 ms)
• การวิเคราะห์ OS: ได้รับค่า ttl=128 เต็มจำนวนโดยตรง แสดงว่าเป็นระบบปฏิบัติการ Microsoft Windows อย่างแน่นอน และอยู่ในวงเครือข่ายแลนเดียวกัน (0 Hop)
💡 ข้อสังเกตเชิง Reconnaissance: เพียงแค่ใช้คำสั่ง ping สั้นๆ เพียงบรรทัดเดียว นักทดสอบเจาะระบบก็สามารถรู้ได้ทันทีว่าโฮสต์ใดเป็น Linux และโฮสต์ใดเป็น Windows เพื่อเลือกเตรียม Payload และ Exploit ให้ตรงเป้าหมายได้อย่างแม่นยำ
